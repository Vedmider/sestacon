# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful and constructive. Harassment or abusive behaviour is not tolerated. Report
concerns to the maintainers via a private [security advisory](https://github.com/Vedmider/sestacon/security/advisories/new)
or by contacting the repository owner.
